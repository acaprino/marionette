# Marionette 0.7.1

Marionette is now released from its Muro project file, `marionette.mp`. The file is the only source: it
carries the package, its inputs at their pinned commits, the records, the history and the built plugin, and
this repository publishes what the file holds.

Nothing changed for a user of the plugin: the catalog, the session policy and the pinned sources are those of
0.7.0. This build was made with Muro 0.10.0. The release carries `marionette.mp` beside
`marionette-0.7.1.zip`, each with its SHA-256.

Verified: this release is published only after the store workflow has validated the package, checked every
source at its pin, built it and run this repository's tests on the file.

Not executed: no host session was run on this build.

- The catalog is 43 capabilities from 18 inputs.

Released from `marionette.mp` (SHA-256 `5271ec43f4f2035bca015d0989ee2ea7a4b889b3357abf07c5ecbb48661807e7`) as pushed to acaprino/marionette at commit `86e40351a52d70d4845fbe7f81571c47a2bb97f1`; the store was written by Muro at commit `5871ee2588967c17c0f3b4b9730df7226dbbc9da`.
