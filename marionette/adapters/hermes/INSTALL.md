The declared policy in `policy.md` registers automatically through `register_system_prompt_section`, preserving the host's core prompt, when the policy is at most 4,000 characters. Hermes accepts no more in one section (8,000 in all of them) and skips what is over, so a longer policy is never cut: it registers a `pre_llm_call` hook instead, and Hermes appends the whole text to the user message of the first turn and again after a compression removed it. That is the turn's context, not the system prompt. Hermes writes a hook return over `hooks.output_spill.max_chars` (default 10,000) to disk and shows a preview; the policy is sent in pieces of at most 8,000 characters, so keep that setting at 8,000 or more. Requires a Hermes version exposing that API; an older host reports an explicit warning instead of claiming activation. After updating a policy, start a new session: a resumed session may retain its persisted system prompt. Not run in a live Hermes conversation. Install or load the complete adapter as a native plugin/package; copying only its skills does not load the policy. The factory never edits host configuration or changes permissions.

This release's source command hooks target other hosts and do not run here.
