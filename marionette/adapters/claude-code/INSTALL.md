# Marionette on claude-code

Install this complete adapter directory as the host's native plugin/package, including its manifest and entrypoint. `skills/marionette` holds the standalone runtime, catalog, license notices and offline `GUIDE.html`. Install the discovery entries `skills/marionette-web-design`, `skills/marionette-product-design`, `skills/marionette-design-review`, `skills/marionette-motion`, `skills/marionette-office`, `skills/marionette-explainer`, `skills/marionette-engineering`, `skills/marionette-papers`, `skills/marionette-token-economy`, `skills/marionette-code-review`, `skills/marionette-working-method`, `skills/marionette-design-docs`, `skills/marionette-implementation`, `skills/marionette-design-file`, `skills/marionette-writing` beside it, in the same skills folder: each holds only a SKILL.md that runs the runtime of `skills/marionette`. Open `skills/marionette/GUIDE.html` for this release's illustrated decision graph and commands. The universal fallback is `python muro.py` inside that folder. See README.md in the source project for current verification limits.

If any is installed on this host, switch it off: hosts pick a skill by its description, and an installed original competes with this coordinator for the same requests.

The declared policy in `policy.md` registers automatically through a native `prompt.compose` module in `hooks/hooks.json`, adding a system-prompt section while preserving the host's other sections. Requires Claude Code mods (2.1.287+) enabled. Install or load the complete adapter as a native plugin/package; copying only its skills does not load the policy. The factory never edits host configuration or changes permissions.

## Install

```sh
claude plugin marketplace add <path of this folder>
claude plugin install marionette@marionette
```

For one session only: `claude --plugin-dir <path of this folder>`. Everything this release declares is active as soon as the plugin is enabled: there is no further step.
